# PaperLens 1.0.1

- 修复多行大纲标题被裁切、章节行重叠及页码被侧栏右边界裁切的问题。
- 修复大纲悬停背景残留及多行同时高亮的问题，增强当前章节的高亮对比，并为高亮背景与页码保留协调的边距。
- 大纲随阅读位置自动定位当前章节，支持同页小节切换；点击大纲可跳转至章节的具体位置。
- 大纲默认全部折叠，阅读进入新章节时展开对应路径。
- 为普通缩略图增加清晰边框，并以更深、更粗的边框标识当前页。
- About 与更新提示显示内部构建号，便于区分同版本修订。
- 工具栏新增阅读模式菜单，可切换单页、双页及连续阅读。
- 非连续阅读模式在 PDF 右上角提供上一页、下一页按钮；双页模式按整组页面翻页。
- 阅读模式与 More 按钮提供一致的悬停反馈；恢复工具栏的 Fit Width 按钮，并在紧凑布局保留该入口。
- 紧凑工具栏隐藏多余分隔线，弹出工具栏按内容收紧两侧空白。
