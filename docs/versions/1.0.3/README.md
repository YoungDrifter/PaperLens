# PaperLens 1.0.3

- 修复连续点击历史记录、阅读模式等顶栏按钮时误触发窗口放大的问题：按钮中心、边缘及控件组内边距都归应用处理，只有控件之间的空白顶栏保留系统双击行为。
- 修复重复启动、点按 Dock 图标重新打开应用时窗口内容尚未就绪导致的崩溃。
- 顶栏图标按钮统一为圆形点击与高亮区域，文件名和页码保留胶囊点击区域。
- 新建标签页改用居中的加号图标，顶栏新增启动页按钮：关闭当前文档并回到启动页，标签页保留。
- 统一单色图标、按钮状态与工具分组，优化窄窗口下的工具布局。
- 阅读模式、更多工具、历史记录、文件信息和紧凑工具使用一致的浅色浮层、圆角与细描边，取消自定义浮层阴影。
- 协调标签栏、侧栏、搜索、批注列表、启动页和设置的颜色、间距与文字层级。
- 启动页的历史记录显示全部条目，超出卡片高度时在卡片内上下滚动查看，也可以一次清空。
- 历史记录的每一条都可以单独删除，不再需要单独的 View all 入口。
- 设置窗口保留标题文字与原生窗口按钮。
- 所有应用自有弹层改为与其他菜单一致的系统弹层：历史记录、文件名、阅读模式、更多工具、紧凑工具，以及高亮与批注颜色的右键菜单、缩略图右键命令、批注卡片与批注列表的操作菜单。
- 历史记录与文件名的弹层与 QuillTeX 完全一致：标题行右上角一次清空，列表统一为图标、标题、路径与悬停底色，逐条删除只在悬停时显示。
- 标签页改为胶囊样式，激活标签为浅色实心胶囊加细描边与很轻的阴影，其余标签保持透明并在悬停时显示浅灰底色。
